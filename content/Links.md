## Accessibility

### Reference

- [Adrian Roselli](https://adrianroselli.com/) has a wealth of knowledge and articles on accessibility topics.  Some interesting ones point out issues in using big tech names as goalposts ([I Don't Care What Google or Apple or Whoever Did](https://adrianroselli.com/2020/03/i-dont-care-what-google-or-apple-or-whomever-did.html)) or in depth breakdowns of why you would choose specific patterns such as where focus goes on a modal ([Where To Put Focus When Opening A Modal Dialog](https://adrianroselli.com/2025/06/where-to-put-focus-when-opening-a-modal-dialog.html))
- [Scott O'Hara](https://www.scottohara.me/blog/) also came up for a me lot when researching good accessibility patterns and also has some interesting thoughts on related topics such as whether and how generative AI like ChatGPT can be used to aid in accessibility ([Setting expectations for asking ChatGPT web accessibility questions](https://www.scottohara.me/blog/2023/02/17/an-ai-dialog.html)) that I still find relevant personally.
- [Accessibility @ Perpendicular Angel Design](https://accessibility.perpendicularangel.com) Anne Gibson has a project that tries to document ways to test websites against WCAG criteria.
- [Accessibility Support](https://a11ysupport.io/) Tests for support for various screen reader and browser combinations.

### Services

- [Accessibility Desk](https://accessibilitydesk.com/) Has some interesting articles but also provides services for accessibility research and audits.

### Courses
- [Practical Accessibility Today](https://practical-accessibility.today/ ) by Sara Soueidan is a great course for developers in particular as it focuses on both general concepts and specific dev issues.  I have completed this one and recommend it.
- [A11y Collective Courses](https://www.a11y-collective.com/courses-overview/)  Several courses that I'm interested in ranging from design-specific to in-depth on ARIA.

### Certification
- [CPACC (Certified Professional in Accessibility Core Competencies)](https://www.accessibilityassociation.org/s/certified-professional) certification is the base level everything else builds on.
- [WAS (Web Accessibility Specialist)](https://www.accessibilityassociation.org/s/wascertification) is the next level up.
- [CPWA (Certified Professional in Web Accessibility)](https://www.accessibilityassociation.org/s/certified-professional-web-accessibility) is the next level up again and requires the first two.
